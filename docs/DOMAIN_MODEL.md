# Domain Model

This document defines the core domain entities within the Aegis ecosystem.

## Core Entities

### User
- **Purpose**: The human identity initiating or authorizing a workflow.
- **Fields**: `user_id`, `role`, `trust_level`, `permissions[]`
- **Security**: Must be authenticated. Serves as the ultimate anchor for permissions.

### Agent
- **Purpose**: The autonomous AI actor requesting to perform actions.
- **Fields**: `agent_id`, `owner_user_id`, `description`, `allowed_tools[]`, `trust_level`
- **Security**: Agents operate on behalf of a User but may have a restricted subset of the User's permissions.

### Session
- **Purpose**: A temporal boundary for a specific workflow or execution run.
- **Fields**: `session_id`, `agent_id`, `user_id`, `start_time`, `end_time`
- **Security**: Used to track state, apply rate limits, and detect runaway tool usage.

### Tool
- **Purpose**: The capability or integration the agent wants to use (e.g., `web.search`, `database.delete`).
- **Fields**: `tool_id`, `name`, `schema`, `trust_level`, `sensitivity`
- **Security**: Tools must be pre-registered. Untrusted tools (e.g., experimental 3rd party MCP servers) inherently increase risk scores.

### Resource
- **Purpose**: The specific target of a Tool operation (e.g., `customer_db`, `github_repo_aegis`).
- **Fields**: `resource_id`, `type`, `environment`, `sensitivity_classification`
- **Security**: Access is governed by environment (e.g., `production` vs `staging`) and data classification.

### Action
- **Purpose**: A normalized request from an Agent to use a Tool on a Resource. (See `ACTION_MODEL.md`)

### Policy
- **Purpose**: A deterministic rule governing whether an action is allowed. (See `POLICY_MODEL.md`)

### Permission
- **Purpose**: An explicit grant linking a User/Agent to a Tool/Resource.
- **Fields**: `grantee_id`, `resource_id`, `operations[]`, `conditions{}`

### TrustLevel
- **Purpose**: An enum representing the verified safety of an entity.
- **States**: `TRUSTED`, `INTERNAL`, `UNTRUSTED`, `SUSPICIOUS`, `BLOCKED`.

### RiskAssessment
- **Purpose**: The output of the Risk Engine for a specific Action. (See `RISK_MODEL.md`)

### ThreatDetection
- **Purpose**: A signal generated by the Threat Engine indicating a potential attack (e.g., Prompt Injection).
- **Fields**: `detector_name`, `confidence`, `severity`, `evidence`

### SecurityDecision
- **Purpose**: The final, authoritative output of Aegis (`ALLOW`, `REVIEW`, `BLOCK`). (See `DECISION_MODEL.md`)

### ApprovalRequest
- **Purpose**: A human-in-the-loop coordination object generated when a decision is `REVIEW`. (See `APPROVAL_MODEL.md`)

### AuditEvent
- **Purpose**: An immutable record of an Action and its resulting SecurityDecision. (See `AUDIT_MODEL.md`)

### SecurityIncident
- **Purpose**: An aggregation of AuditEvents or ThreatDetections that cross a critical threshold, requiring SecOps intervention.
